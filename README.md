# Chapeuzinho (demo)

Demo de um jogo de terror curto inspirado na Chapeuzinho Vermelho: uma floresta de desenhos em papel, de traço preto grosso, onde ela anda sempre em frente.

**Jogar:** https://gentsuyama.github.io/chapeuzinho-demo/ (melhor no computador, com fones de ouvido)

- **W** anda · **Shift** corre · **A/D** desvia
- **mouse** ou **Q/E** olha para os lados (nunca para trás) — mas não olhe para o vazio por muito tempo
- **T** deixa os clarões dos relâmpagos mais suaves

Arte da floresta, do lobo e dos rostos gerada com Google Flow e montada em Three.js.
